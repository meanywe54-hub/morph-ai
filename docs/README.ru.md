# MORPH: краткий путеводитель

MORPH — экспериментальная Python-платформа для проверки изменений в поведении AI-агентов. Она собирает ошибки, получает кандидат улучшения, сравнивает его с исходным агентом, хранит свидетельства и поддерживает явное подтверждение, маршрутизацию, откат и одноразовый holdout.

Текущая предметная область узкая: сложение целых чисел со знаком. Универсальный coding agent и доказанное самоулучшение пока не реализованы. Реальные локальные попытки не дали принятого улучшения; отрицательные результаты опубликованы в [сводке](../reports/README.md).

Для запуска без модели, API-ключей и Docker нужны [Python 3.11+](https://www.python.org/downloads/) и [Git](https://git-scm.com/downloads):

```powershell
git clone https://github.com/meanywe54-hub/morph-ai.git
cd morph-ai
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m morph.cli demo
.\.venv\Scripts\python.exe examples/bounded_evolution.py
```

Это не требует WSL, перезагрузки или изменения политики PowerShell. В демонстрациях генератор фиксированный: они проверяют инфраструктуру, а не доказывают появление новой способности у LLM.

Базовые примеры не обращаются в сеть. Команды с внешней моделью передают ей явно заданные задачи и могут стоить денег. Сырые отчёты могут содержать запросы и ответы: храните их в локальной игнорируемой папке. В публичном релизе распространяется сводка измерений, а не личные сообщения или сырые логи.
